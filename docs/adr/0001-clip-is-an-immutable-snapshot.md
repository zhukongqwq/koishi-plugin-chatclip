# ADR-0001：Clip 是不可变快照

**状态**：已接受（2026-11-20）

## 背景

收藏的动机是"怕丢"。如果快照跟随原消息的编辑/撤回而更新，那么最需要被保住的内容恰恰会消失。但完全不可变又意味着用户无法修正自己收藏时的错误（比如误收藏了无关消息）。

## 决策

Clip 一旦写入即不可变：

- 消息内容、发送者、时间、附件都在收藏那一刻固化；
- 原消息后续的编辑、撤回、删除**不触发**任何更新；
- 唯一的可变部分是 Clip 自身的元数据：`visibility`、`deletedAt`。

## 后果

- 反撤回成为免费副产品；
- 数据库只增不改，查询路径简单；
- 需要额外的"重新收藏"路径来取最新版本，而不是原地刷新 —— 这由幂等规则（ADR-0004）保证不会产生重复行；
- 存储只增，靠软删除控制可见性，不靠物理清理。
