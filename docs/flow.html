chatclip 全部命令验证流程

按 ① → ② → ③ → ④ 的顺序走一遍，每步都写了「执行什么 / 应该看到什么」。带 ⚠ 的是异常分支，可以最后再试。

1收藏

核心路径：引用一条消息 → 落库 → 回编号
clip
先引用任意一条消息再发。回复 已收藏 #A0001 · 1 条 · 仅自己，第二行是 clip show #A0001 查看。
clip -s channel
可见性改成「本群可见」。回复里的可见性字段变成 本群可见。
clip
对同一条消息再发一次：应回 这条消息已经收藏过了：#A0001（幂等，不会重复入库）。
clip
⚠ 异常 不引用直接发：回 请先引用一条消息再发送 clip。
clip
⚠ 异常 引用一条带图片的消息：回复后面多一行 🖼 1；控制台详情里能看到缩略图。
clip
⚠ 异常 引用一条合并转发：回复里条数变成转发条数之和；如果取不到内容会多一行 ⚠️ 降级：forward-unavailable，这是正常的。

2展示

文字列表 / 单条图片 / 强制形态
clip list
纯文字列表：📚 我的收藏 · 共 N 条 · 第 1/1 页，每条三行（编号/发送者/时间/可见性 + 25 字摘要 + 可选引用与图数），末尾是翻页与查看提示。
clip list --image
出一张气泡风总览图（聊天气泡 + 合并转发卡片）。
clip show #A0001
单条渲染成大字卡：引号、粗体正文、—— 昵称、userId、引用块、附件、右下时间。编号写 1024 或 #A1024 都行。
clip show 1024 --text
不出图，改成纯文字详情（标题行 + ①②③ 消息 + 附件链接）。
clip show 1024 --bubble
强制出气泡形态，用来和默认的大字卡对比。
clip help
打印全部指令清单（收藏 / 浏览两段）。别名：收藏、chatclip、fav。

3检索与筛选

先确认收藏数量够多，再来跑这一组
clip search 渲染
回 🔍「渲染」 · 我的收藏 · N 条 + 命中的列表；没有命中回 📭 没有找到包含「渲染」的收藏。
clip list --from 白露
只列这个人发的收藏；多个发送者用英文逗号分隔。
clip list --since 7d
只看最近 7 天。支持 7d / 24h / 30m / 2026-11-01，配合 --until 取区间。
clip list --here
只看本群收藏；--all 只列公开的（跨群可见的那些）。
clip list 2
翻到第 2 页（每页条数由控制台配置里的 pageSize 决定，默认 10）。

4管理与控制台

软删除 → 回收站 → 硬删除，以及导出
clip rm #A0001
软删除，回 已删除 #A0001（可恢复）；这条从 clip list 里消失。
clip export #A0002
回一份 JSON（消息 + 附件 + 元信息）；加 --html 导出可离线打开的 HTML。
控制台 → 聊天收藏
顶部筛选：关键词 / 发送者 / 可见性 / 状态（全部 / 仅正常 / 回收站） / 时间范围。表格行首有多选勾选框。
勾选若干行 → 批量软删除
批量栏显示 已选 N 条；删除后把状态切到「回收站」就能看到它们，行尾按钮变成 恢复 / 硬删除。
硬删除（仅回收站里的行）
先弹确认框；确认后消息与附件记录一并删除。未软删除的收藏不会出现硬删除按钮，后端也会跳过它们。
清空回收站
批量栏右侧，一次删掉所有已软删除的收藏；回 已永久删除 N 条 或 回收站是空的。
测试顺序建议：① 收藏 3 条（一条纯文字、一条带图、一条合并转发）→ ② 各看一次 list / list --image / show / show --text → ③ 搜一次、按发送者和时间各筛一次 → ④ rm 一条后进控制台回收站，试批量恢复与硬删除。 如果某一步的表现和上面写的不一样，把那条回复原文发我，我按回复内容定位。 测试完记得让我关掉我开的 koishi 实例（目前只剩你自己那个在跑，我的已经关了）。
